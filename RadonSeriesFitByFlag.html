Как работать

1) вставьте временную серию в указанном формате в поле для ввода и нажмите «Загрузить серию из поля для ввода»;
2) нажмите кнопку с типом участка, который будет присвоен выбранному далее интервалу;
3) зажав Ctrl и левую кнопку мыши, протяните курсор вправо, чтобы задать временному интервалу выбранный тип участка;
4) выбранные участки будут автоматически аппроксимированы кривой, а её параметры выведены в таблицу ниже, либо появятся в подсказке при наведении курсора на участок;
4) по окончании работы экспортируйте таблицу со всеми данными.

📖 Описание приложения доступно по ссылке GitHub
