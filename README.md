# Radon Series Fit By Flag
Это одностраничное приложение для обработки временных серий объемной активности (ОА) радона, полученных с радон-мониторов.
Доступно по ссылке Radon [Series Fit By Flag](https://vsz2020.github.io/RadonSeriesFitByFlag/).

Приложение дает возможность удобной обработки участков накопления радона в помещении и участков разбавления (за счет притока уличного воздуха) радона. 
Пользователь лишь выбирает участки временной серии, которые будут обработаны приложением автоматически.
Выбранные участки серии подгоняются под функцию вида

C(t)=C0 exp(-lambda t) + phi/lambda exp(-lambda t)

Для подгонки выбранного участка под модельную функцию накопления/разбавления ОА радона применяется стандартный метод Левенберга-Марквардта.

## Как работать с программой
1. Импортировать временную серию (из буфера обмена, файла TXT/CSV, вставкой в поле ввода).
2. На графике отобразится временная серия.
3. Нажать кнопку `Накопление (Н)`, или `Разбавление (Р)`, или `Температурные колебания (ТК)` для дальнейшего выбора участка накопления, разбавления ОА радона или её температурных колебаний.
4. Масштабировать нужный участок временной серии вращением колесика мыши.
5. Зажав Ctrl, выделить левой кнопкой мыши (ЛКМ) интервал, значениям которого будет присвоен выбранный тип участка (накопление, разбавление или температурные колебания).
6. Очистить присвоенный тип можно зажав Ctrl+ПКМ (правую кнопку мыши) и выбрав участок для очистки.
7. Повторить действия 4-5 для других интервалов.
8. Программа автоматически выполнит подгонку каждого интервала и выведет оптимальные значения параметров phi, lambda, C0 в таблице под графиком. Получить текущее значения параметров подгонки можно наведя курсор на интересующий участок (если для него задан тип интервала, кроме типа ТК).
9. Все данные по интервалам с оптимальными параметрами можно экспортировать в файл TXT/CSV или скопировать в буфер обмена в виде таблицы с пояснениями.

> **Примечание**
>
> Единицы измерения величин выбираются автоматически. Для ОА радона оценивается максимальное значение. Если все значения порядка единицы, то задается размерность `кБк/м3`. Если десятки и сотни - `Бк/м3`.
> Для phi и lambda единицы измерения устанавливаются исходя из минимальной длительности интервала между парой соседних значений. Величина phi может быть выражена в `Бк/м3/мин` или `Бк/м3/ч`, а lambda в `1/мин` или `1/ч`.
